## 🔄 三位一體黃金工作流

1. **KyteShelf (收集)**：抓住多來源檔案晃動滑鼠，置物架立即浮現暫存。
2. **KyteView (檢驗)**：按 Space 空白鍵毫秒級快速確認相片、簡報與影音細節。
3. **KyteRename (重構)**：拖入規則引擎，自動抽取 EXIF/ID3 標籤，拓撲排序安全批次更名。
