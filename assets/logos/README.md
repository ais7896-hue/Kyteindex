# Kyte Suite 標誌與圖標資源庫 (Logo & Brand Assets)

本目錄包含 **Kyte Suite 總標誌**、**KyteView**、**KyteShelf** 與 **KyteRename** 的向量 SVG 與透明背景高解析度 PNG 檔案。

---

## 目錄架構

```
assets/logos/
├── svg/                     # 向量 SVG 格式（1024x1024 viewBox，無損縮放）
├── png-512/                 # 512x512 透明背景 PNG（標準高解析度）
└── png-1024/                # 1024x1024 透明背景 PNG（超高解析度 Retina）
```
