隱私權政策 Privacy Policy

核心隱私承諾：100% 本機純離線運作

Kyte Suite（包含 KyteView、KyteShelf 與 KyteRename，以下統稱「本軟體」或「我們」）極度重視您的個人隱私與數位主權。 我們深知桌面檔案的敏感性，因此本軟體從底層架構上即設計為純本機離線運作工具。

1 零個人檔案上傳 (Zero Telemetry)

您的所有文件內容、相片、影片、音訊、壓縮檔目錄樹、相片 EXIF 拍攝資訊、音樂 ID3 標籤、自黏便箋內容以及硬碟檔案路徑，完全在您個人電腦的本機記憶體（RAM）與 CPU/GPU 內處理。

  • 本軟體絕不將您的任何個人檔案內容上傳至任何雲端伺服器。
  • 本軟體不包含任何第三方行為追蹤、監控探針（Telemetry）或數據分析 SDK。
  • 本軟體不會掃描、建構或向外傳送您的資料夾結構與個人敏感資訊。

2 唯一連網行為（僅限正式版序號驗證）

當您購買正式版並在軟體中點擊「開通序號」或「解除綁定」時，系統會透過 HTTPS 加密連線傳送以下極低敏感度數據至 Cloudflare Worker 授權伺服器：

授權金鑰 (License Key)
您購買時所取得的正版序號字串。
匿名硬體指紋雜湊
由 Windows MachineGuid 經單向 SHA-256 不可逆雜湊，無法反推電腦內容。

上述資訊僅用於防範序號遭盜用，並校驗「單組序號同時最多啟用 2 台個人裝置」之額度。完成開通後，本機會簽發離線加密憑證，日後在無網路環境下依然 100% 正常可用。

3 官方網站瀏覽資訊

當您訪問 Kyte Suite 官方網站時，網站託管平台（GitHub Pages 與 Cloudflare CDN）可能會記錄標準網路請求標頭（包含瀏覽器類型、請求時間與來源 IP 位址），此為網際網路傳輸之必要基礎日誌。我們未在網站嵌入侵犯性之跨站廣告追蹤 Cookie。

4 聯絡我們

若您對本隱私政策或個人資料處理有任何疑問，歡迎隨時透過客服信箱與我們聯繫： support@aisming.com

Core Privacy Commitment: 100% Local & Offline

Kyte Suite (encompassing KyteView, KyteShelf, and KyteRename, collectively referred to as "the Software", "we", "us", or "our") is strictly dedicated to user privacy and digital sovereignty. The Software is architected from the ground up as a strictly offline local desktop utility.

1 Zero Content Telemetry

Your file contents, documents, images, video/audio streams, archive file trees, photo EXIF metadata, audio ID3 tags, sticky note text, and filesystem paths are processed strictly within your device's local memory (RAM) and processor (CPU/GPU).

  • The Software never uploads, intercepts, scans, or transmits your personal files or folder contents to any cloud server.
  • The Software contains zero user behavior analytics, spyware, or third-party telemetry tracking SDKs.
  • The Software does not catalog or transmit your filesystem directory structure.

2 Information We Process (License Activation Only)

When activating a commercial license key or releasing a device quota, the Software communicates with our Cloudflare Worker verification API over an encrypted HTTPS connection. The data transmitted is limited exclusively to:

License Key
The alphanumeric string issued with your purchase.
Anonymized Hardware Fingerprint
A one-way irreversible SHA-256 hash of the Windows MachineGuid.

This data is used solely to enforce the "maximum 2 concurrent devices per license" quota. Upon activation, an offline certificate is stored locally, allowing the Software to remain 100% usable without an active internet connection.

3 Website & Server Logs

When visiting our official websites (hosted on GitHub Pages and Cloudflare CDN), standard server request logs (browser user agent, timestamps, and IP addresses) are generated by the hosting infrastructure. We do not deploy invasive cross-site advertising or tracking cookies.

4 Contact Us

If you have any questions regarding this Privacy Policy or your data, please contact our support team at: support@aisming.com
